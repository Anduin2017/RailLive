## 复测方法

在 RTX 4090 的独立 Chromium 中关闭浏览器网络缓存，固定为 2467 × 1257 CSS 像素。从 11 月 19 日 13:00 开始以苏州为中心、缩放 8 级运行。正放及倒放各 95 秒，然后以 1× 跟随 G1211 五秒。计时从切到目标视野开始。首屏要求出现可见列车，新版还要求当前所需格子全部就绪。

`python3 tests/browser/benchmark_region.py 8080` 可复跑。位置更新频率统计提交给地图的数据源变化，空窗统计动画回调观察到的空数据源。响应字节统计区域数据的压缩响应体，不含底图、HTTP 头和车次详情。启动时已经获取的目录单列统计。帧间隔来自浏览器动画回调。

新版在两个方向观测到的空窗次数及累计空窗时间均为零。区域资源缓存估算峰值为 24.7 MiB，其口径包括解码后的瓦片和几何包。所有动画阶段中，按秒采样的整页 JavaScript 堆峰值为 242.3 MiB，其中还包含地图、页面和已展开的轨迹。全程有 3.21 MB 作为预取下载，1.65 MB 随后被实际使用，截至观测结束尚有 1.56 MB 未使用。播放中首次缺少字体字形时会记住该结果，本次测速开始后基础字形文件只请求一次。
